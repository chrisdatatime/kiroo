# Kiroo (protótipo)

Escritório-jogo isométrico para produzir vídeos de produto com agentes de IA.

## Rodar
```bash
npm install
npm run dev
```
Abra o endereço que aparecer no terminal (normalmente http://localhost:5173).

## Controles
- **WASD / setas** ou **clique no chão**: andar
- **E**: falar com o agente ou usar o objeto ao lado
- **Esc**: fechar janelas

Geração, conferência e exportação são simuladas. Veja `CLAUDE.md` para a arquitetura e as regras de produto.
